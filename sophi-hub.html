The opportunity

The SOPHI Hub.
Six pillars, one operating system.

The hub is not a valet app. It is the config-driven operating layer that turns every property SOPHI operates into the same predictable P&L unit — a shift, a report, a review, a rehire — priced to what the property already sells.

Operations

Incidents & write-ups

Every service-recovery event, damage claim, or friction point captured in the same schema across every property.

  • Photo, timestamp, GPS on every entry
  • Auto-routing by severity and vertical
  • Insurance-grade paper trail
Operations

Shift daily reports

The single artifact GMs open every morning: last night's covers, revenue, tips, incidents, and staffing gaps, per property, in one view.

  • Auto-generated at 03:00 local time
  • Owner-configurable KPI set
  • Text-first, mobile-first

Architecture posture

Config-driven accounts

Every property is a config object. New verticals ship as configuration, not code.

Zero-trust by role and tag

Reads gated by property, role, and tag. Cross-tenant access requires explicit provisioning.

Kill-switched outbound

Every outbound integration (SMS, review platform, POS) behind a per-property switch.

Vendor-neutral AI

Model layer swappable. No dependency on a single model provider for the operating loop.
